## PyTorch：理解并实现模型训练

作业要求理解 Tensor、形状、CPU/GPU、Dataset/DataLoader、batch/epoch，以及神经网络的前向传播、损失、梯度、反向传播和参数优化。这些概念在本周的 MNIST 实验中形成了完整流程。

| 学习内容              | 在实验中的对应                                                                  |
| --------------------- | ------------------------------------------------------------------------------- |
| Tensor 与 shape       | 图片为 `[B, 1, 28, 28]`，展平后为 `[B, 784]`，潜在表示为 `[B, d]`         |
| Dataset 与 DataLoader | 使用 MNIST 的 60,000 张训练图片和 10,000 张测试图片，常规 batch 为 256          |
| Batch 与 epoch        | batch 是一次更新使用的样本；epoch 是遍历一次完整训练集                          |
| CPU 与 GPU            | 模型与输入通过 `.to(device)` 放到相同设备；当前代码选择 CUDA 或 CPU           |
| 网络层与激活函数      | Linear 改变特征维度，ReLU 引入非线性，Sigmoid 将重建输出限制到 `[0, 1]`       |
| 优化器与学习率        | Adam 根据梯度更新参数；学习率影响更新幅度，不能把预训练与 refinement 的设置混淆 |

一次训练更新包括：

```python
optimizer.zero_grad()
reconstructed = model(images)
loss = criterion(reconstructed, images)
loss.backward()
optimizer.step()
```

这里，前向传播产生重建图片，损失衡量重建与原图的差异，反向传播计算梯度，优化器才实际更新参数。真实数字标签没有参与这个训练过程。

我也区分了 `train()`、`eval()` 和 `no_grad()`：前两者控制模块的训练/评价行为，`no_grad()` 关闭梯度记录。`eval()` 并不会自动关闭 VAE 中自己编写的随机采样。保存与加载模型也是作业的学习内容，目前还需要在 Notebook 中补充实践。

### 拓展：Tensor 的每个维度到底表示什么

一张灰度图片的形状是 `[1, 28, 28]`：第一个 1 是通道数，后两个 28 是高度和宽度。组成一个 batch 后，最前面增加样本维度，得到 `[B, 1, 28, 28]`。

```python
images, labels = next(iter(train_loader))
print(images.shape)  # 常规批次：[256, 1, 28, 28]
print(labels.shape)  # [256]
flat = images.flatten(start_dim=1)
print(flat.shape)    # [256, 784]
```

`start_dim=1` 表示保留第 0 维的样本数量，把每张图片内部的维度展平。展平只是改变排列方式，不是降维：每张图片仍有 784 个像素值。真正的降维发生在线性层将 784 个输入变成更少的特征时。

本周图片通常是 `float32`，标签是整数。特征可以是负数，不需要像图片一样限制到 `[0,1]`；AE 潜在层没有 Sigmoid，本身是合理设计。

Tensor 还具有设备与梯度信息：形状说明数据如何组织，`device` 说明计算在哪里进行，`requires_grad` 说明是否追踪导数。训练时参数通常需要梯度，输入图片则不必设为 `requires_grad=True`，参数仍能正常更新。

转为 scikit-learn 使用的 NumPy 数组时，可写：

```python
Z_numpy = z.detach().cpu().numpy()
```

`detach()` 脱离计算图，`cpu()` 将数据移到 CPU，`numpy()` 转为数组。若 `z` 原本是在 `no_grad()` 中计算的，通常已经不需要梯度。

### 拓展：一个 epoch 实际进行了多少次更新

训练集有 60,000 张图片，batch size 为 256，且没有设置 `drop_last=True`：

$$
60000=234\times256+96.
$$

因此，一个 epoch 有 234 个完整 batch 和一个 96 张图片的小 batch，共 **235 次参数更新**。10 个 epoch 通常有 2,350 次更新，20 个 epoch 通常有 4,700 次更新。

每个 epoch 打乱数据不会改变样本总数，只改变分批与出现顺序。不同顺序会影响梯度更新轨迹，也是神经网络实验需要固定随机种子的原因之一。

测试特征提取时使用 `shuffle=False` 是为了便于保持顺序。即使打乱，只要特征与真实标签在同一轮迭代中配对收集，仍可正确评价；问题出在将不同迭代顺序中的特征与标签混用。

### 拓展：Linear 与激活函数做了什么

`nn.Linear(784, 256)` 对一个 batch 计算：

$$
H=XW^\top+b,
$$

其中 $X$ 为 `[B,784]`，$W$ 为 `[256,784]`，$b$ 为 `[256]`，输出 $H$ 为 `[B,256]`。每个输出特征都是输入的加权组合，再加一个偏置。

如果连续堆叠线性层却没有非线性激活，多层仍可以合并为一个仿射变换。ReLU 使网络能够学习更复杂的映射：

$$
\operatorname{ReLU}(u)=\max(0,u).
$$

Sigmoid 为：

$$
\operatorname{sigmoid}(u)=\frac{1}{1+e^{-u}}.
$$

它适合本实验的像素输出范围，但不意味着网络在做数字分类。这里没有输出 10 类概率的分类头，解码器输出的是 784 个像素值。

### 拓展：用一个小例子理解反向传播

考虑一个用于解释梯度的简化模型，它不是完整 AE：

$$
u=ax+b,\quad \hat y=\operatorname{ReLU}(u),\quad L=(\hat y-y)^2.
$$

令 $x=3,a=2,b=1,y=5$。前向计算得到：

$$
u=2\times3+1=7,\quad \hat y=7,\quad L=(7-5)^2=4.
$$

反向传播按链式法则计算：

$$
\frac{\partial L}{\partial\hat y}=2(7-5)=4,\qquad
\frac{\partial\hat y}{\partial u}=1.
$$

于是：

$$
\frac{\partial L}{\partial a}=4\times1\times3=12,\qquad
\frac{\partial L}{\partial b}=4\times1\times1=4.
$$

若使用学习率 $0.01$ 的简单梯度下降：

$$
a'=2-0.01\times12=1.88,\qquad b'=1-0.01\times4=0.96.
$$

重新前向计算，$\hat y'=1.88\times3+0.96=6.6$，损失变为 $2.56$。

```python
import torch

a = torch.tensor(2.0, requires_grad=True)
b = torch.tensor(1.0, requires_grad=True)
x = torch.tensor(3.0)
prediction = torch.relu(a * x + b)
loss = (prediction - 5.0).pow(2)
loss.backward()
print(a.grad.item(), b.grad.item())  # 12.0, 4.0
```

PyTorch 会根据前向运算建立计算图，自动完成这些局部导数的组合。[官方 autograd 教程](https://docs.pytorch.org/tutorials/beginner/basics/autogradqs_tutorial.html)

### 拓展：为什么需要清空梯度，Adam 又改变了什么

默认情况下，多次 `backward()` 会将梯度累加到参数的 `.grad` 中。常规逐 batch 更新需要先清空旧梯度；只有有意进行梯度累积时，才会跨多个 batch 保留它们。

`loss.backward()` 不会直接修改权重；`optimizer.step()` 才做更新。上面的数值例子使用简单梯度下降；Notebook 实际使用 Adam，它会根据梯度的历史一阶、二阶统计自适应调整各参数的更新，不能把每次实际变化都直接等同于 `lr * 当前梯度`。

学习率过小可能在给定轮数内训练不足，过大可能扰动已学到的表示或使优化不稳定。因此，“预训练阶段需要学好表示”和“refinement 阶段希望小幅调整表示”可以使用不同学习率。本周 deep-clustering 中把预训练学习率设为 `1e-5`，正是需要单独审视的设置。

### 拓展：训练模式、梯度模式与随机性是三件事

| 操作                | 影响                     | 不会自动完成的事情                     |
| ------------------- | ------------------------ | -------------------------------------- |
| `model.train()`   | 切换模块为训练模式       | 不会自动训练或调用优化器               |
| `model.eval()`    | 切换模块为评价模式       | 不会关闭梯度，也不会关闭手写的随机采样 |
| `torch.no_grad()` | 不记录该区域的反向计算图 | 不会自动切换模块模式                   |

本周网络没有 Dropout 或 BatchNorm，但仍保留模式切换的规范。VAE 的 `torch.randn_like()` 没有根据 `self.training` 分支，因此在 `eval()` 下也照常采样。

### 拓展：保存权重为什么能保证任务之间的衔接

下面是可补充的保存/加载示例，不表示当前 Notebook 已执行了它：

```python
# 保存 Task 1 训练好的 16 维 AE 参数
checkpoint_path = "ae16_pretrained.pt"
torch.save(model.state_dict(), checkpoint_path)

# 新文件中先定义相同结构，再恢复参数
loaded_model = Autoencoder(latent_dim=16).to(device)
state = torch.load(
    checkpoint_path,
    map_location=device,
    weights_only=True,
)
loaded_model.load_state_dict(state)
loaded_model.eval()
```

两个文件应指向同一个明确的保存路径。`state_dict` 保存参数及相关缓冲区，不会替你定义网络结构；层名称和尺寸必须匹配。若要完整恢复继续训练的状态，还应保存优化器状态与训练轮数。[官方保存与加载教程](https://docs.pytorch.org/tutorials/beginner/basics/saveloadrun_tutorial.html)

重新建立一个相同结构的 AE 只会重新初始化权重，不等于复用了 Task 1 的表示。加载后也应重新提取对应特征、计算基线中心，避免使用另一份模型的旧数组。

## Task 1：AE 表示学习与聚类

### 实验内容

按照作业给出的结构，我实现了全连接 AE：

```text
784 → 256 → 64 → d → 64 → 256 → 784
```

分别尝试 $d=8,16,32$。编码器把图片压缩为潜在表示 $z$，解码器将其还原为图片：

$$
z=f_\phi(x),\qquad \hat{x}=g_\theta(z).
$$

训练使用 MSE、Adam、学习率 `1e-3` 和 10 个 epoch。训练后展示原图与重建图，再使用编码器输出做 K-means，而不是对重建图片聚类。

按照要求，我比较了 Raw、PCA 与 AE，并使用真实标签在聚类结束后计算 ARI、NMI。进一步增加了 L2 归一化实验：AE、Raw、PCA 都保留原始组，并增加相同后处理的对照组。

### 当前实验成果

以下结果来自 `week3_autoencoder.ipynb` 当前保存的输出，均在同一批 10,000 张测试图片上评价。

| ------ | ---: | -------: | -------: | --------: | --------: |
| Raw    |  784 |   0.3820 |   0.5035 |    0.4215 |    0.5437 |
| PCA-8  |    8 |   0.3629 |   0.4836 |    0.3800 |    0.4847 |
| AE-8   |    8 |   0.4038 |   0.5203 |    0.4727 |    0.5909 |
| PCA-16 |   16 |   0.3705 |   0.5005 |    0.4193 |    0.5171 |
| AE-16  |   16 |   0.2751 |   0.4247 |    0.4803 |    0.5927 |

AE-8、16、32 最后一轮的训练平均 MSE 分别为 **0.0213、0.0167、0.0142**。这些是训练日志中的平均值，不是最终模型的测试重建误差。

### 对表示与维度的理解

增大潜在维度，在本次实验中改善了重建，却没有使原始特征的聚类指标单调提高。这说明更大的表示可以保留更多信息，但这些信息不一定都有助于区分数字类别。

AE 只通过重建目标学习表示，没有直接要求同类数字靠近。网络可能保留笔画粗细、位置等重建相关信息，也可能形成不适合欧氏距离的潜在坐标尺度。因此，重建误差低不能保证 K-means 表现好。

L2 归一化把每个非零向量变为单位长度：

$$
\tilde z=\frac{z}{\|z\|_2}.
$$

这会去除每个样本的整体模长，保留方向与各维相对比例。两个单位向量之间满足：

$$
\|u-v\|_2^2=2-2\cos\angle(u,v).
$$

本次 AE 的明显改善，说明移除模长后，距离更适合数字类别划分。它没有增加新信息，也没有重新训练网络。L2 是逐样本特征处理，与像素缩放、逐维标准化、参数的 L2 正则化不同；也不能消除所有潜在空间变形。

PCA 在训练集上拟合，再对测试集投影，最后分别归一化 8、16、32 维特征。这样可以比较相同后处理下的不同表示，而不把 AE 独有的处理收益当成网络本身的优势。

### 拓展：AE 为什么是无监督的，却仍然有训练目标

监督分类需要“图片属于哪个数字”作为目标；AE 使用图片自身作为目标。训练样本实际上是 $(x,x)$，而不是 $(x,y_{\mathrm{digit}})$。因此，无监督并不意味着没有损失或目标值，而是没有使用真实类别来训练。

16 维 bottleneck 迫使网络压缩信息，但不意味着每一维都有清晰的人类语义。第 1 维未必是数字类别，第 2 维未必是笔画粗细；这些特征是为共同完成重建而学习的。

本周 AE 的 MSE 是对所有样本和像素取平均：

$$
L_{\mathrm{MSE}}=\frac{1}{B\times784}
\sum_{i=1}^B\sum_{p=1}^{784}(\hat x_{ip}-x_{ip})^2.
$$

若某个像素真实值为 1，预测为 0.8，该像素的平方误差为 0.04。损失只关心像素差异，没有直接检查“两个数字 7 的潜在特征是否接近”。这也是为什么重建与聚类必须分别评价。

### 拓展：Raw、PCA 和 AE 分别保留了什么

| 表示 | 如何形成                           | 主要约束                         |
| ---- | ---------------------------------- | -------------------------------- |
| Raw  | 直接展平 784 个像素                | 保留原有像素坐标，未学习压缩映射 |
| PCA  | 投影到训练数据的主成分             | 线性投影，保留主要方差方向       |
| AE   | 经可训练的非线性编码器得到潜在向量 | 与解码器一起优化重建             |

PCA 可写为：

$$
z_{\mathrm{PCA}}=(x-\bar x)V_d,
$$

其中 $V_d$ 的列是相互正交的主成分方向。AE 具有更灵活的非线性映射，但灵活不等于聚类更好：它也可能改变原有的距离关系。

在线性映射、平方误差和合适最优解等条件下，低维 AE 与 PCA 的主子空间存在联系。当前 AE 使用 ReLU 和 Sigmoid，并不等同于那个线性特例。[《Deep Learning》AE 章节](https://www.deeplearningbook.org/contents/autoencoders.html)

即使重建完全相同，潜在坐标也可能不唯一。设 $A$ 为可逆变换，编码器输出改为 $z'=Az$，解码器再先乘 $A^{-1}$，就可以恢复原来的解码输入。若 $A$ 拉伸不同方向，欧氏距离会改变。

这解释了一个重要限制：**重建要求约束的是编码与解码的组合，不会单独保证编码空间具有理想的聚类几何。**

### 拓展：潜在维度为何不能只看重建误差来选

维度过小可能丢失笔画结构；维度较大可能保留更多细节，也可能保留与类别无关的变化。更低的重建误差只说明图片信息保留得更多，不能说明类别信息占比更高。

本周原始 AE-8 的 ARI 高于 AE-16，并不能单独证明 8 维总是更合适。不同模型还受到初始化、训练顺序与优化轨迹影响。需要在相同预算下重复多个种子，再结合目标任务选择维度。

### 拓展：L2 去掉模长，为什么会改变距离

把每个向量分解为长度与方向：

$$
z_i=r_i u_i,\qquad \|u_i\|_2=1.
$$

两个样本的原始距离为：

$$
\|z_i-z_j\|_2^2=r_i^2+r_j^2-2r_ir_j\cos\angle(u_i,u_j).
$$

距离同时取决于两个模长和夹角。L2 后 $r_i=r_j=1$，模长因素被移除。

例如，假设 A、B 是同类图片，C 是另一类：

```text
A = [1, 2]
B = [10, 20]
C = [2, 1]
```

原始距离 $d(A,B)\approx20.12$，$d(A,C)\approx1.41$。L2 后 A 与 B 重合，而 A 与 C 的距离约为 0.63。这个例子说明距离处理可以改变样本间的亲近关系，不是对真实实验每个样本的直接解释。

**统一将所有向量乘以同一个正数**不会改变理想 K-means 的分组，只会改变距离单位；**每个样本分别除以自己的模长**则会改变几何结构。这两种缩放不能混淆。

### 拓展：四种“归一化/正则化”不是同一件事

| 操作                        | 作用对象     | 本周的含义                               |
| --------------------------- | ------------ | ---------------------------------------- |
| `ToTensor()` 的像素缩放   | 像素值       | 把 0～255 转为 0～1                      |
| L2 特征归一化               | 每个样本向量 | 统一向量长度，保留方向                   |
| `StandardScaler`          | 每个特征维度 | 用训练集均值和标准差调整各列尺度         |
| 参数正则化，如 weight decay | 网络权重     | 在训练中限制参数，不是直接归一化每个样本 |

L2 的潜在代价是丢掉长度中的信息。如果模长有助于区分类别，归一化反而可能有害；VAE 的对照已经展示了这种情况。标准化也不能保证改善，更不应直接用测试标签挑选处理方式。

### 拓展：为什么全连接 AE 的重建会平滑

当前模型通过 784→256→64→d 的路径压缩图片，然后用全连接层重建。它没有显式采用卷积对局部笔画结构的先验；这是可比较的设计选择，尚不能据此证明它就是指标偏低的主要原因。

当表示不能充分区分细节时，像素重建可能出现灰色过渡或多个可能形状的折中。更宽的网络、卷积结构或去噪训练都可以作为后续独立对照，但本周已经验证的低成本改进是聚类前的特征处理。

## Task 2：VAE 与生成模型

### 模型与学习内容

VAE 不只输出一个潜在向量，而是为每张图片预测一个近似后验分布：

$$
q_\phi(z\mid x)=\mathcal N\left(\mu(x),\operatorname{diag}(\sigma^2(x))\right),
\qquad p(z)=\mathcal N(0,I).
$$

当前编码器是 `784 → 256 → 64`，之后分别输出 16 维 `mu` 和 `logvar`。`mu` 是后验均值，`logvar` 是对数方差，而不是图片的像素均值或方差。

通过重参数化采样：

$$
\epsilon\sim\mathcal N(0,I),\qquad
z=\mu+\exp(\tfrac12\mathrm{logvar})\odot\epsilon.
$$

随机性来自 $\epsilon$，而均值和标准差仍处于可微计算图中，所以梯度可以传回编码器。

训练同时考虑重建与 KL：

$$
L=L_{\mathrm{reconstruction}}+L_{\mathrm{KL}}.
$$

重建项使用 BCE，要求保留解释输入的信息；KL 项约束近似后验接近先验，支持从先验采样生成图片。这两项共同决定表示的信息量与分布结构，但不直接要求形成数字类别对应的簇。

ELBO 是需要最大化的下界，代码最小化的是其负值的采样估计。重建损失与 KL 损失之和不能直接称为 ELBO 本身。

按照作业要求，我实现了重建展示、从标准正态先验生成样本，以及后验均值聚类。聚类使用确定性的 `mu`；生成新图片则使用从先验采样的 `z`。

VAE 使用 16 维潜在变量、Adam `lr=1e-4`，训练轮数由 10 增加到 20。最后一轮训练日志为：

|   总损失 |   重建项 |   KL 项 |

### 拓展：先验、后验与近似后验分别回答什么问题

- **先验 $p(z)$**：还没有观察某张图片时，对潜在变量的假设。当前是标准正态，不根据具体图片改变。
- **真实后验 $p_\theta(z\mid x)$**：看到图片后，哪些潜在变量更可能解释它？根据贝叶斯公式，它涉及边缘概率 $p_\theta(x)$，通常难以直接计算。
- **近似后验 $q_\phi(z\mid x)$**：编码器给出的可计算近似，用均值与方差描述潜在不确定性。

这里沿用 VAE 的常见记号：$\phi$ 表示编码器参数，$\theta$ 表示解码器参数。

每张图片都有自己的 $\mu$ 和 $\sigma$。把一个 batch 的所有图片先求平均，与编码器为每张图片输出一个均值向量，完全是两件事。

标准正态先验不表示“所有图片的 mu 都相同”，也不表示生成的图片只能有一种形状。非线性解码器可以把连续潜在空间映射成复杂的图片分布；先验本身也没有标注哪个区域属于哪个数字类别。

### 拓展：为什么预测 logvar 而不是直接预测方差

方差必须为正，而线性层可以输出任意实数。输出 $v=\log\sigma^2$ 后，通过指数变换得到正方差：

$$
\sigma^2=e^v,\qquad \sigma=e^{v/2}.
$$

`logvar=0` 表示方差为 1，不是方差为 0。`logvar=log(4)` 表示方差为 4、标准差为 2。代码中计算的是 `std = exp(0.5 * logvar)`，因为采样需要标准差。

### 拓展：重参数化的具体数值与梯度

假设：

$$
\mu=[1,-1],\quad \mathrm{logvar}=[0,\log4],\quad
\epsilon=[0.5,-0.5].
$$

那么：

$$
\sigma=[1,2],\qquad z=[1+1\times0.5,-1+2\times(-0.5)]=[1.5,-2].
$$

将一次采样得到的 $\epsilon$ 视为固定数值，逐维导数为：

$$
\frac{\partial z_j}{\partial\mu_j}=1,\qquad
\frac{\partial z_j}{\partial v_j}=\frac12e^{v_j/2}\epsilon_j.
$$

若示例损失为 $L=z_1+z_2$，则对 `mu` 的梯度为 `[1,1]`，对 `logvar` 的梯度为 `[0.25,-0.5]`。这说明随机采样没有阻断均值、方差参数到损失的可微路径。

### 拓展：KL 项怎样约束一个高斯后验

一个潜在维度的后验为 $\mathcal N(\mu,\sigma^2)$，与标准正态的 KL 为：

$$
D_{\mathrm{KL}}=\frac12\left(\mu^2+\sigma^2-1-\log\sigma^2\right).
$$

三个数值例子：

| 后验                 |        KL | 含义                                 |
| -------------------- | --------: | ------------------------------------ |
| $\mu=0,\sigma=1$   |         0 | 与先验完全一致                       |
| $\mu=2,\sigma=1$   |         2 | 均值偏离先验中心产生代价             |
| $\mu=0,\sigma=0.5$ | 约 0.3181 | 即使均值相同，分布宽度不同也产生代价 |

用 $v=\log\sigma^2$ 表示，其导数为：

$$
\frac{\partial D_{\mathrm{KL}}}{\partial\mu}=\mu,\qquad
\frac{\partial D_{\mathrm{KL}}}{\partial v}=\frac12(e^v-1).
$$

单独优化 KL 会将均值推向 0、方差推向 1；重建目标则要求表示携带图片信息，两者共同形成折中。方差趋近 0 也会产生越来越大的 KL 代价，因此 VAE 不能无代价地退化成完全确定的编码器。

如果所有图片的后验都几乎等于先验，潜在变量就很难携带输入信息，这与后验塌缩有关。但仅凭损失大小或几张模糊图片，不能断定发生了塌缩；还需查看 KL、各维 mu 的变化及解码器对 z 的依赖。

### 拓展：ELBO 为什么是下界，为什么训练 loss 是它的负值

VAE 希望图片的边缘概率较高：

$$
p_\theta(x)=\int p_\theta(x\mid z)p(z)\,dz.
$$

使用近似后验可以得到恒等式：

$$
\log p_\theta(x)=\mathcal L(x)+
D_{\mathrm{KL}}\big(q_\phi(z\mid x)\,\|\,p_\theta(z\mid x)\big).
$$

因为 KL 非负，所以：

$$
\mathcal L(x)\le\log p_\theta(x).
$$

这里的下界又可以写成：

$$
\mathcal L(x)=
\mathbb E_{q_\phi(z\mid x)}[\log p_\theta(x\mid z)]
-D_{\mathrm{KL}}\big(q_\phi(z\mid x)\,\|\,p(z)\big).
$$

注意两个 KL 的第二个分布不同：恒等式中的 KL 比较近似后验与**真实后验**；训练目标中的 KL 比较近似后验与**先验**。不要把它们当成同一个量。

最大化 ELBO，等价于最小化“负的期望对数似然 + KL”。训练通过采样近似重建期望，从而得到代码中的重建项加 KL。[VAE 原论文](https://arxiv.org/html/1312.6114v11)

> [!tip] 💡 记忆方式
> ELBO：重建对数似然 **减** KL，越大越好。训练 loss：重建代价 **加** KL，越小越好。

### 拓展：BCE 为什么不会总是趋近于 0

一个像素的目标值为 $t$，预测值为 $p$，BCE 为：

$$
\ell(t,p)=-t\log p-(1-t)\log(1-p).
$$

对于白色像素 $t=1,p=0.8$，损失约为 0.2231；对于灰度软目标 $t=0.8,p=0.8$，损失约为 **0.5004**。后者即使预测与目标相同，BCE 也不是 0，而是该软目标对应的熵。

MNIST 含灰度，当前代码将其作为 BCE 的软目标。因此，不能用“BCE 必须接近 0”判断训练是否成功，也不能与像素平均 MSE 的数值直接比较。Sigmoid 输出的连续像素值可形成灰色边缘；把图片阈值化只改变显示/输出，不证明模型恢复了真实细节。

### 拓展：loss 的 reduction 会改变 KL 的相对权重

当前重建项计算方式是 `reduction="sum"` 再除以 batch size，即先将一张图片的 784 个像素相加，再对图片平均。KL 也是先对潜在维度求和，再对图片平均。

如果只把重建项改成 `reduction="mean"`，它会额外除以 784；KL 不变时，相对约束就增强了。具体来说：

$$
L_{\mathrm{new}}=\frac{L_{\mathrm{recon,old}}}{784}+\beta L_{\mathrm{KL}}.
$$

乘以 784 后，与原来的像素求和尺度对应为：

$$
784L_{\mathrm{new}}=L_{\mathrm{recon,old}}+784\beta L_{\mathrm{KL}}.
$$

所以改变 reduction 不是只改变打印数字，它还改变了两项目标的相对作用；这个相对系数结论也不等于 Adam 的每步参数更新必然按该比例变化。

### 拓展：重建、后验均值解码、先验生成的区别

| 操作           | 潜在量来自哪里                      | 是否依赖指定图片 |
| -------------- | ----------------------------------- | ---------------- |
| 随机重建       | $q(z\mid x)$ 中采样的 z           | 是               |
| 确定性重建展示 | 该图片的后验均值 mu                 | 是               |
| 生成新图片     | 先验 $\mathcal N(0,I)$ 中采样的 z | 否               |

解码 `mu` 能消除这一步的采样变化，但一般有：

$$
g(\mathbb E[z])\ne\mathbb E[g(z)].
$$

因为解码器非线性，`decoder(mu)` 不一定是所有随机重建图片的严格平均，也不保证一定最清晰。训练阶段仍需要按照 VAE 的采样目标优化，不能因为想让展示稳定就随意删除训练采样。

聚类使用 mu 可以避免一次随机采样给每张图片加入额外变化，使同一模型的表示可重复。mu 本身也不一定具有最适合 K-means 的尺度，因此后处理仍需对照验证。

### 拓展：如何理解 beta、潜在维度与 epoch 的关系

$\beta$ 控制信息保留与先验约束的折中。较小的 $\beta$ 可能改善细节保留，也可能使潜在空间更不适合先验采样；较大的 $\beta$ 可能加强约束，也可能压掉有用信息。$\beta\ne1$ 时应称为加权目标，而不是直接等同于标准 VAE 的负 ELBO。

潜在维度改变时，KL 的求和项数量也改变；网络宽度、优化难度和有效使用的维度都会影响结果。因此，改变维度后不能只凭 KL 总值增大就认定正则化更坏。

epoch 是优化预算。更多训练可能改善重建，却改变表示的几何结构，聚类指标不必一直改善。本周 20 轮与 30 轮的差异，是这种现象的一个实例。

这些因素应先分别改变再比较。标准正态先验也不意味着对每个 mu 向量做 L2 一定合理：后验均值的模长可能包含有用信息，20 轮 VAE 的归一化对照正好提醒了这一点。

## Task 3：表示学习与聚类目标的相互作用

### 实验方法

作业要求从 Task 1 的预训练编码器出发，先用 K-means 初始化中心，再做 refinement，与固定 AE + K-means 基线比较。本周的核心目的不是复现最先进方法，而是理解表示学习与聚类目标的相互影响。

我实现了两种方案：

| 方案     | 实际更新方式                                                                  |
| -------- | ----------------------------------------------------------------------------- |
| Option A | 固定当前分配和中心，用重建项与中心距离项更新 AE；再提取特征、重新运行 K-means |
| Option B | 每个批次计算到最近中心的距离；中心作为可训练参数，与 AE 一起通过梯度下降更新  |

联合目标为：

$$
L=L_{\mathrm{reconstruction}}+\lambda L_{\mathrm{clustering}}.
$$

聚类结果通过距离损失指导编码器：图片的特征被推动靠近所属或最近的中心。这里的簇编号来自 K-means，不是真实数字标签。

两个目标共同作用于编码器参数：

$$
\nabla_\phi L=
\nabla_\phi L_{\mathrm{reconstruction}}
+\lambda\nabla_\phi L_{\mathrm{clustering}}.
$$

为了公平比较，基线在 refinement 前保存，A、B 各自复制原始模型、标签和中心；A 通过图片索引保证打乱批次后仍能找到正确簇分配。

### 当前实验成果及解释

当前 deep-clustering Notebook 独立预训练 AE，使用 `lr=1e-5` 和 10 轮，最后一轮训练 MSE 为 **0.0700**。A、B 的学习率为 `1e-4`、$\lambda=0.001$，各进行 5 轮或 epoch。评价在 60,000 张训练图片上完成。

| 方法              |    ARI |    NMI |
| ----------------- | -----: | -----: |
| 固定 AE + K-means | 0.0209 | 0.0510 |
| Option A          | 0.2741 | 0.3858 |
| Option B          | 0.0386 | 0.0744 |

这组结果相对基线提高，但基线训练较弱，refinement 又增加了训练并提高了学习率。因此，尚不能单独将提升归因于聚类目标，需要加入 $\lambda=0$ 的继续重建训练对照。

之前的实验中也出现过 refinement 低于基线的情况。结合这些结果，我理解了：相互作用既可能有利，也可能有不利影响；优化当前分组的紧凑性，并不保证提高真实数字类别的一致性。

此外，重建损失下降、聚类损失上升并不矛盾。当前 A 第一轮的加权总损失约为 **0.06766**，第五轮约为 **0.03745**，虽然聚类分项上升，总目标仍下降。A 每轮还会更新分配和中心，分项日志不要求单调下降。

### 拓展：写出与代码一致的聚类损失

A 固定当前分配 $c_i$，编码器产生 $z_i$，本轮中心为 $\mu_k$：

$$
L_{\mathrm{cluster,A}}=\frac{1}{Bd}\sum_i\|z_i-\mu_{c_i}\|_2^2.
$$

分母包含 $d$，因为当前 `MSELoss` 对 batch 和特征维度都取平均。本节的 $\mu_k$ 是**聚类中心**，与 VAE 每张图片的后验均值 $\mu(x)$ 不同。

B 每个 batch 选择最近中心：

$$
L_{\mathrm{cluster,B}}=\frac{1}{Bd}\sum_i\min_k\|z_i-\mu_k\|_2^2.
$$

最近中心的选择是离散的；在最近中心固定的区域内，选中的距离项仍可对特征与中心求导。当前代码没有对 K-means 的整个求解过程反向传播。

对一个二维例子，$z=[3,4]$、目标中心为 $[1,2]$：

$$
L_{\mathrm{cluster}}=\frac{(3-1)^2+(4-2)^2}{2}=4,
\qquad \frac{\partial L}{\partial z}=[2,2].
$$

这个梯度经编码器的链式法则传回参数；实际 `step()` 更新的是网络权重，而不是把一个脱离网络的 z 数组直接改掉。

### 拓展：为什么两个目标可能冲突

用一个简单参数说明折中，不把它当作真实 AE 的全部行为：

$$
L_r=(w-2)^2,\qquad L_c=w^2,\qquad L=L_r+\lambda L_c.
$$

重建项希望 $w=2$，聚类项希望 $w=0$。联合目标的最优点为：

$$
w^*=\frac{2}{1+\lambda}.
$$

$\lambda=0$ 时得到 2；$\lambda=1$ 时得到 1。联合优化不可能同时让这两个互相冲突的损失都为 0。

在网络中，用 $g_r$、$g_c$ 表示两类目标对编码器的梯度。它们方向相近时可以相互帮助，方向相反时可能互相抵消。损失分项数值大，并不自动表示梯度更大；需要考察对同一组参数的导数。

例如，当前日志的加权聚类项很小，总损失可以通过降低重建项而下降，同时允许聚类项有所增加。梯度下降也不保证随机 batch 的损失每步单调下降。

### 拓展：当前簇标签为什么可能强化错误

K-means 给出的分配只是当前特征空间中的分组。如果本来属于不同数字的图片被分到同一簇，距离损失仍会推动它们靠近同一个中心；如果同类数字被分开，则可能继续向不同中心移动。

这些分配可以作为训练目标，但不是可靠的真实数字标签。只优化已有分组，可能把初始错误强化，而不是修正它。

对于不确定的分配，后续可以研究软分配或降低其权重；本周未完成这类实验，不能把它们当作已有改进成果。

### 拓展：损失下降的尺度捷径与特征塌缩

若特征和中心同时缩放为 $cz$、$c\mu$，距离平方变成原来的 $c^2$ 倍。编码器末层与解码器首层可以相互补偿，使重建近似不变。因此，原始距离损失可能因为坐标缩小而下降，而类别分组没有真正改善。

这个例子要求中心也相应缩放；只缩小特征而固定任意中心，并不保证损失下降。A 重新计算中心、B 通过梯度更新中心，都可能改变中心位置与尺度。

尺度缩小也不等同于已经完全塌缩。完全失去区分能力是更强的结论，需要检查样本间差异、有效维度、簇分布与重建能力，不能只看特征方差或聚类损失变小。

### 拓展：为什么编码器和中心需要协调更新

编码器更新后，图片的特征位置改变。中心若仍停在旧位置，就可能跟不上表示空间的变化。

A 通过重新运行 K-means 更新中心；B 依赖中心参数的梯度更新。给不同参数组相同学习率，并不保证它们在特征空间中的变化速度相同。

如果需要诊断 B，可以分别评价：

1. 新特征分配到 B 训练后的中心，衡量完整联合模型。
2. 固定 B 编码器后重新运行 K-means，诊断这个表示在充分重新拟合中心后是否更好。

第二种结果属于额外诊断，不应替换第一种而仍使用相同名称。

### 拓展：为什么 lambda 等于 0 的对照很重要

需要区分三种情况：

| 实验                     | 编码器是否继续训练 | 聚类项是否参与 |
| ------------------------ | ------------------ | -------------- |
| 固定 AE + K-means        | 否                 | 否             |
| $\lambda=0$ 的继续训练 | 是                 | 否             |
| $\lambda>0$ 的联合训练 | 是                 | 是             |

比较后两种、并匹配起点和预算，才能更好地分辨聚类项的影响。否则指标提高可能只是因为训练时间增加或学习率改变。

还要保持表示处理一致。若基线对特征做了 L2，而 refinement 使用原始距离，则不仅训练发生了变化，评价几何也改变了；应该单独说明并补齐相同处理的对照。

## 指标理解与公平实验设计

### ARI 与 NMI 为什么不要求簇编号等于数字编号

例如，真实标签为 `[0,0,1,1]`，聚类标签为 `[7,7,3,3]`。两者编号不同，但分组完全相同，ARI 与 NMI 都为 1。直接逐元素比较标签是否相等，不能当作正确的聚类评价。

- **ARI** 从样本对是否同组的角度评价划分，并校正随机一致性。1 表示相同划分，随机划分通常接近 0，也可能为负。
- **NMI** 衡量两个划分共享的信息，归一化到 0～1；编号置换不影响结果。它不像 ARI 那样进行随机一致性校正。

ARI 为 0.48 不是“48% 分类准确率”，NMI 为 0.59 也不是“59% 的图片分类正确”。[scikit-learn 聚类评价说明](https://scikit-learn.org/stable/modules/clustering.html#clustering-performance-evaluation)

### Silhouette 为什么可能与 ARI、NMI 不一致

对样本 $i$，令 $a(i)$ 为到同簇其他样本的平均距离，$b(i)$ 为到其他簇的平均距离中最小的一个：

$$
s(i)=\frac{b(i)-a(i)}{\max(a(i),b(i))}.
$$

它描述当前表示与距离下的紧凑性和分离程度，不知道哪个簇对应数字 7。值接近 1 表示较好分离，接近 0 表示边界不明确，负值可能表示分配不合适。

不同表示或归一化改变了距离，这个指标也会变化。本周 VAE 的 ARI/NMI 显著高于 AE，却有略低的 Silhouette，不能据此否定 VAE 的类别划分表现。

### 三种评价对象应该分开

| 要评价什么 | 可以观察什么                           | 不能直接推断什么             |
| ---------- | -------------------------------------- | ---------------------------- |
| 图片重建   | 验证/测试重建损失、视觉笔画是否保留    | 真实类别一定分得更好         |
| 表示与聚类 | ARI、NMI、簇分布、明确距离下的内部指标 | 生成图片一定更清晰           |
| 生成能力   | 先验样本、分布覆盖与质量等额外分析     | 高聚类指标就代表生成模型优秀 |

当前作业以基础理解与实验比较为主，不需要把一个指标当作模型所有能力的总评分。

### 为什么保存的 Notebook 输出也需要审视

执行顺序、重新初始化、继续训练、变量重用都会改变模型状态。保存输出可以作为当时结果的证据，但代码修改后，旧结果不自动更新。

一个可靠的比较应说明：初始权重、数据划分、特征处理、训练轮数、学习率、损失权重、随机种子和最后的分配方式。评价前应从对应的最终模型重新提取特征。

随机种子有助于重复一次结果，但一次成功仍可能具有偶然性。多个种子的均值与波动更适合判断小幅改进是否稳定。

### 无监督训练与参数选择的边界

本周训练和 K-means 没有使用真实数字标签。若不断根据测试集 ARI/NMI 选择 epoch、beta 或归一化方式，测试集就参与了方法选择，不能再将最终分数视为完全独立的评估。

若需要调参，应事先留出验证数据；若要求全过程的参数选择也完全无监督，验证阶段应使用不依赖真实类别的标准。重建误差或内部指标可以提供信息，却仍不保证语义聚类最优。

本周讨论中的单次参数对照属于探索性学习实验，帮助理解机制，而不是证明某一设置对所有数据都最优。

### 连接到后续联邦聚类的思考

当不同客户端各自学习编码器时，即使重建都很好，潜在坐标也可能具有不同尺度、旋转或语义对应。不同坐标系中的中心不能直接当成可比较的同一类向量。

因此，后续联邦聚类不仅需要考虑模型参数如何训练，还要考虑各客户端表示是否共享可比较的空间。这是由本周潜在空间“不唯一”的现象引出的延伸问题，尚不是已经完成的联邦实验。

## 本周主要收获

1. **理解了完整的神经网络训练流程。** 能把数据形状、前向传播、损失、梯度与参数更新对应起来，而不只调用训练代码。
2. **理解了表示学习与聚类之间的联系。** 聚类算法不变，特征表示或距离处理变化，结果仍可能明显不同。
3. **区分了不同训练目标。** 重建损失、VAE 正则化、中心距离与最终聚类评价指标各自衡量不同内容。
4. **认识到实验控制的重要性。** 比较需要明确模型起点、数据集、训练预算、后处理和评价方式；旧特征或旧输出不代表更新后的模型。
5. **学会根据结果修正判断。** AE 不必然优于 PCA，L2 不必然有效，更多训练或联合优化也不必然提高指标，结论需要限定到具体实验。
